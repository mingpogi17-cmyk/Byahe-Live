# Paws & Pals PH 🐾

Production-ready single-file Pet Super App for the Philippines.

## Features
- **Top Banner Badge**: `🐾 Paws & Pals PH | Beta v1.0`
- **Multi-Language Switcher**: Toggle between English and Tagalog seamlessly.
- **Digital QR ID Generator**: Instant QR ID badge creation for pet identification.
- **OCR Vaccine Tracker**: Scan vaccine records with image text extraction & automated alarms/reminders.
- **Emergency Blood Donor SOS**: Real-time SOS alerts and donor search for pet blood emergencies.
- **Responsive Mobile-First UI**: Dark slate & emerald green design system optimized for mobile & desktop deployment on Vercel.

## Vercel Deployment
This repository is optimized for direct static deployment on Vercel. Simply import this directory into Vercel or point Vercel root directory to `paws-and-pals-ph`.
